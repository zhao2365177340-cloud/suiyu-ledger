# 岁余 · 使用说明

> 面向普通用户的操作指南。所有数据都保存在你的手机里；应用没有账号体系，也不会上传任何账单。

## 一、开始之前

1. 在手机上安装「岁余」（Android 8.0 及以上）。
2. 第一次打开会自带一份**虚构的示例数据**（覆盖最近 16 个月，方便你立刻看到统计、报表和个税测算的样子）。
3. 如果想从零开始：进入「家庭」页，在「数据」里选择「清空流水」或「重置为示例」。首页如果提示「当前为示例数据」，点「去处理」可直接跳到家庭页。

## 二、认识主界面

底部有 5 个 Tab，中间是圆形的「＋」按钮：

- **概览**：这个月的收入、支出、结余、结余率，环比变化，近 6 个月趋势，以及导入账单、记一笔、报表、财务体检、个税测算五个快捷入口；下方还有一张「家庭净资产 · 财务体检」摘要卡。
- **流水**：按天滚动的完整流水账，能看每一笔明细、点进去修改，还能长按多选删除。
- **统计**：按分类、按月对比、按日历看支出或收入。
- **报表**：一张可以分享的月度家庭财务报表。
- **家庭**：家庭成员、分类、偏好设置、数据导出与备份。
- **中央「＋」**：随时打开「记一笔」。

截图导入、财务体检与个税测算是二级页面：从概览快捷入口（或报表页的体检摘要）进入，左上角返回即可回到主界面。

## 三、从零到第一张报表

按下面的顺序走一遍，大约 5 分钟：

1. **清空示例数据**：家庭 → 数据 → 清空流水。
2. **记一笔**：点中央「＋」，输入金额 → 点一个分类 → 点「保存」。
3. **导入一批账单**：概览 → 导入账单，选择几张微信/支付宝/银行账单截图，等待本机识别。
4. **复核草稿**：逐条确认金额、分类、成员和日期，把不确定的分类点开改掉，然后全选入账。
5. **看统计**：切到「统计」，选本月、支出、家庭视角，看环形占比和分类排行；点某一类可下钻明细。
6. **切到「报表」**：选择本月，阅读自动生成的总述、收支总览、结构、成员分账和财务健康。
7. **分享**：点「分享报表」，通过系统分享面板发到微信或存为备忘。
8. **（可选）个税测算**：在报表页点「个税测算」，填收入与扣除项，查看结果并分享。

## 四、手动记一笔

1. 点中央「＋」，页面打开时数字键盘已就位。
2. 输入金额；需要时在顶部切换「支出 / 收入」、点日期按钮改日期。
3. 点一个分类，点「保存」（键盘右下角的按钮也可直接保存）。

补充说明：

- 成员默认是「我」，可在分类下方点选其他成员；账户、商户、备注在「账户、商户与备注（可选）」里展开填写，不填不影响保存。
- 金额最多两位小数，非法金额会提示「请先输入金额」，未选分类会提示选择分类。
- 已保存的流水可以在概览的「最近流水」里点开，进入「编辑一笔」修改；编辑页右上角可以删除这一笔，删除前会二次确认，删除后统计与报表同步更新。

## 五、用截图导入账单

1. 进入「导入账单」，顶部会说明：全部在本机识别，不上传。
2. 点选图，一次最多选 9 张截图（微信收支明细、支付宝账单、银行 App 明细等）；如果是银行短信，也可以直接把文字粘贴进来。
3. 等待本机 OCR 识别并解析成草稿卡。每张卡上会显示金额、分类、成员、日期、来源角标（微信 / 支付宝 / 银行 / 短信）和识别置信度。
4. 逐条复核：点卡片可修改类型、金额、分类、成员、日期和备注。与已有流水「同类型、同金额、3 天内、商户或备注相近」的记录会被标为疑似重复，请按需取消勾选。
5. 确认无误后全选并批量入账，完成后会提示「已入账 N 笔」。
6. 你改过的分类会被记住：下次识别到同一商户时自动归到该分类。
7. 识别不出的截图会有「手动补录」出口；导入页还提供解析样例自检（10 条样例，显示通过/失败），方便你判断识别环境是否正常。

建议：截图尽量完整、清晰，避免只截半行或叠加多层弹窗；一次导入同一类账单（比如只导微信或只导支付宝），复核会更快。

## 六、看统计

1. 顶部选择月份，切换「支出 / 收入」，再选「家庭」或某位成员。
2. **结构**：环形图看占比，下面的排行列出各分类金额与比例；点分类进入该类别的明细。
3. **对比**：分组柱状图对比本月与上月（或成员之间），折线图看近 6 个月或近 12 个月趋势。
4. **日历**：热力图看这个月哪几天花得多，同时给出日均支出、最大单笔和零支出天数。

所有页面的数字来自同一套统计口径，同一笔钱在概览、统计、报表里看到的金额是一致的。

## 七、生成并分享报表

1. 切到「报表」，选择月份。
2. 页面会依次给出：一段自动总述（收入、支出、结余、结余率、环比与同比）、收支总览、结构占比、环比变化 Top、同比对比、成员分账（点成员可展开近 6 个月趋势和主要分类）、家庭财务健康、自动洞察列表。
3. 点「分享报表」，选择微信、备忘录等任意应用即可发送。分享内容是可复制的纯文本，接收方不需要安装「岁余」。
4. 当月没有数据时，报表会显示空态和引导，不会出现一张全是「—」的表。

## 八、家庭成员与分类

- **家庭名称**：在「家庭」页点名称即可修改，首页问候语和报表总述都会使用它。
- **成员**：可新增、修改、删除成员，设置名称、头像 emoji、主题色和身份标签（本人 / 配偶 / 子女 / 父母 / 其他）。删除成员后，他名下的流水会自动归到「我」，不会丢账。
- **分类**：内置分类（支出 13 个、收入 7 个）只能查看，不能删除；自定义分类可新增和删除。删除自定义分类后，原来的流水会归到「其他」或「其他收入」。

## 九、个税测算与模拟申报

在报表页点「个税测算」进入，按步骤填写：

1. **收入**：工资薪金、全年一次性奖金、劳务报酬、稿酬、特许权使用费。
2. **三险一金**：可按工资基数估算，也可逐项填写。
3. **专项附加扣除（7 项）**：子女教育、3 岁以下婴幼儿照护、继续教育、住房贷款利息、住房租金、赡养老人、大病医疗。每项都有「政策说明」可展开，金额可自填或按提示自动算。
4. **其他扣除**：个人养老金、税优健康险等。
5. **结果**：年度应纳税所得额、适用税率、速算扣除数、应纳税额、已预缴估算、应补/退税额、综合税负率；同时给出年终奖「单独计税」与「并入综合所得」两种方案的对比和推荐，以及 12 个月预扣明细。
6. **模拟申报**：查看表格式的申报数据，点「分享测算结果」可发给家人或自己留存。

**请注意**：个税结果是根据你填写的数据做的测算，仅供参考，不构成税务建议；最终以税务机关口径与你的实际申报为准。

## 十、数据备份与导出

进入「家庭」页的「数据」：

- **导出 CSV**：生成收支明细表（日期、时间、方向、金额、分类、成员、商户、账户、来源、备注），可用于 Excel 或交给家人核对。
- **导出备份**：生成一份可读的 JSON 文件，包含成员、分类、流水、设置和识别规则，用于换机或留档。
- **从备份恢复**：选择之前导出的备份文件恢复账本，恢复前会覆盖当前数据。
- **清空流水 / 重置为示例**：清空只删流水、保留成员与自定义分类；重置会恢复示例数据。

导出的文件保存在应用私有目录并通过系统分享/保存面板交给你，应用本身不会上传。

## 十一、触感、隐私与主题

- **触感**：在「家庭」页可以一键关闭触感，或选择轻、标准、明显三档强度并试振。记账保存、导入完成、删除、开关切换的反馈各不相同。
- **金额遮罩**：打开后各页金额显示为 `¥ ••••`，适合给家人看手机或截图分享时使用。
- **主题**：跟随系统、浅色、深色三选一，深色模式下配色会整体切换，而不是简单反色。

## 十二、流水明细与批量删除

「流水」是逐日查看和整理账本的地方，入口在底部 Tab 第二个。

- **看明细**：默认按「今天 / 昨天 / 具体日期」分组，每组右侧显示当天支出小计（有收入时也会显示收入）。每笔显示分类、成员、商户、来源与时间。
- **筛选**：顶部可切换月份、全部/支出/收入，还能按成员筛选；右上角显示当前列表的笔数与收支合计。
- **改一笔**：点任意一笔进入编辑页，改金额、分类、成员、日期、备注或账户后保存；编辑页右上角垃圾桶可删除这一笔。
- **多选删除**：长按任意一笔进入多选，左侧出现勾选框；再点其他笔可追加/取消；底部工具条显示「已选 N 笔」和合计，点「全选」可选中当前筛选下的全部记录，点「删除」二次确认后批量删除。
- **一键清空**：流水页右上角「清空」会删除账本内全部流水（成员、分类、设置保留），需要二次确认；建议先在「家庭 → 数据」导出备份。
- **安全设计**：多选时按系统返回键先退出多选、不退出应用；删除类操作都有二次确认与警示触感。

## 十三、财务体检与资产录入

「财务体检」回答的是比「这个月花了多少」更根本的问题：家里的资产、负债与现金流结构，能不能扛住风险。入口：概览的「财务体检」快捷入口、首页净资产卡，或报表页底部的「家庭财务体检」摘要。

- **资产**：点「添加资产」，选类别（现金/活期、定期存款、理财/货基、股票基金债券、保单现金价值、自住房、投资房产、车辆、借出/应收、其他），填当前估值即可；点已有资产可修改或删除。
- **负债**：添加房贷、车贷、消费贷、信用卡或借款，填剩余欠款；有月供的再填「每月还款」，用于计算月供收入比。
- **工作与家庭情况**：填职业/行业、单位性质、工作年限、收入稳定性，勾选配偶是否在职、赡养老人与子女数、医保/重疾/寿险及保额。
- **固定收支**：默认按近 6 个月流水估算（工资类收入、居住/通讯/教育支出 + 负债月供）；如果觉得估算不准，可在「工作与家庭情况」里手动填写月固定收入与固定支出（留空即自动）。
- **结果**：总览卡显示净资产与综合评分环；「六维风险雷达」展示流动性、负债健康、收入稳定、储蓄能力、保障覆盖、配置均衡；「关键风险指标」列应急金月数、资产负债率、月供收入比、储蓄率等；「体检建议」按薄弱项给出具体缺口与动作。
- **分享**：右上角「分享」或底部「分享家庭体检报告」，生成纯文本报告，可发家庭群或存档。
- **注意**：资产估值请按当前可变现价值填写；评分是经验模型，不是监管标准，也不构成投资/保险/信贷建议。

## 十四、常见问题

- **我的数据存在哪？** 在应用私有目录的 `ledger.json` 里，只有本机的「岁余」能读取。没有账号，没有云同步。
- **换手机怎么办？** 先在旧手机「数据 → 导出备份」，把 JSON 文件发送到新手机，安装后在「从备份恢复」中选择它。
- **识别不准怎么办？** 截图质量决定识别效果。尽量使用完整的账单页截图；导入后逐条复核，改过的分类会被记住。
- **为什么统计和银行 App 对不上？** 统计只计入「纳入统计」的流水，并按设备本地时区的自然月划分；转账、内部划账等可以不计入。请检查是否有重复入账或漏导。
- **不想看到示例数据？** 家庭 → 数据 → 清空流水，即得到一份空白账本。
