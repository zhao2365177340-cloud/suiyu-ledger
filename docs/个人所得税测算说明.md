# 个人所得税测算说明（2026 年度综合所得汇算）

> 本文档说明「岁余」App 内「个税测算 / 模拟申报」模块的政策依据、计算公式、整数运算规则、样例校验与误差边界。
> 测算结果仅用于家庭预算与税务规划参考，**不是正式纳税申报**，最终以税务机关认定为准。

## 1. 适用范围与政策时点

| 项目 | 说明 |
|---|---|
| 适用年度 | 2026 年度综合所得汇算（对应 2026 年 1 月 1 日 — 12 月 31 日取得的综合所得） |
| 税制依据 | 2019 年起施行的《中华人民共和国个人所得税法》及其实施条例、《个人所得税专项附加扣除暂行办法》 |
| 专项附加扣除标准 | 2023 年提高后的标准，2026 年度继续适用（子女教育 / 3 岁以下婴幼儿照护 2,000 元/月/孩等） |
| 全年一次性奖金 | 单独计税政策延续至 **2027 年 12 月 31 日**；本模块同时计算「单独计税」与「并入综合所得」两方案并取低推荐 |
| 征收方式 | 综合所得按年计算、按月（次）预扣预缴，年度终了后汇算清缴、多退少补 |

本模块不处理经营所得、分类所得（利息股息红利、财产租赁、财产转让、偶然所得）、境外所得抵免、减免税优惠等情形。

## 2. 计算口径与公式

### 2.1 综合所得收入额折算

综合所得包括工资薪金、劳务报酬、稿酬、特许权使用费四项。计入年度收入额时并非简单相加：

| 所得项目 | 收入额折算 | 说明 |
|---|---|---|
| 工资、薪金所得 | 收入全额 | 含奖金、津贴、补贴等（全年一次性奖金另按 §2.6 处理） |
| 劳务报酬所得 | 收入 × 80% | 减除 20% 费用后的余额 |
| 稿酬所得 | 收入 × 80% × 70% | 先减除 20% 费用，再按 70% 计算，即收入 × 56% |
| 特许权使用费所得 | 收入 × 80% | 减除 20% 费用后的余额 |

> 计税时按「先 80%、再 70%」两步四舍五入到分（与税法表述一致），不使用 56% 一步折算。

### 2.2 综合所得应纳税所得额

```
应纳税所得额 = 综合所得收入额
             − 基本减除费用 60,000 元/年
             − 专项扣除（三险一金个人缴纳部分）
             − 专项附加扣除
             − 依法确定的其他扣除
```

若计算结果为负数，按 0 处理（不产生负税额，也不结转）。

### 2.3 年度税率表（综合所得）

| 级数 | 全年应纳税所得额（元） | 税率 | 速算扣除数（元） |
|---:|---|---:|---:|
| 1 | 不超过 36,000 | 3% | 0 |
| 2 | 超过 36,000 至 144,000 | 10% | 2,520 |
| 3 | 超过 144,000 至 300,000 | 20% | 16,920 |
| 4 | 超过 300,000 至 420,000 | 25% | 31,920 |
| 5 | 超过 420,000 至 660,000 | 30% | 52,920 |
| 6 | 超过 660,000 至 960,000 | 35% | 85,920 |
| 7 | 超过 960,000 | 45% | 181,920 |

```
综合所得应纳税额 = 应纳税所得额 × 适用税率 − 速算扣除数
```

### 2.4 专项附加扣除标准（7 项）

| 扣除项目 | 标准 | 关键条件 |
|---|---|---|
| 子女教育 | 2,000 元/月/孩 | 父母可选择各扣 50% 或由一方 100% 扣除；扣除至子女全日制学历教育结束 |
| 3 岁以下婴幼儿照护 | 2,000 元/月/孩 | 分摊方式同子女教育 |
| 继续教育 | 学历（学位）400 元/月；职业资格 3,600 元/年 | 学历教育最长累计 48 个月；职业资格在取得证书当年一次性扣除 |
| 住房贷款利息 | 1,000 元/月 | 首套住房贷款利息，最长累计 240 个月；夫妻可选择一方扣除 |
| 住房租金 | 1,500 / 1,100 / 800 元/月 | 一类：直辖市、省会（首府）、计划单列市及国务院确定的其他城市；二类：市辖区户籍人口 > 100 万；三类：≤ 100 万。**与住房贷款利息互斥** |
| 赡养老人 | 独生子女 3,000 元/月；非独生子女分摊 3,000 元/月总额 | 非独生子女每人不超过 1,500 元/月 |
| 大病医疗 | 自付累计超过 15,000 元的部分，年限额 80,000 元 | 医保报销后个人负担（医保目录范围内自付）部分；**只能在年度汇算时扣除**，预扣预缴阶段不扣 |

本模块的默认口径：按月扣除的项目（子女教育、婴幼儿照护、赡养老人、住房贷款利息、住房租金）按本年度 12 个月计算；继续教育学历按用户填写的本年度可扣月数（0–12）计算；大病医疗按用户填写的全年自付累计计算。

### 2.5 其他扣除

| 扣除项目 | 限额 | 说明 |
|---|---|---|
| 个人养老金 | ≤ 12,000 元/年 | 缴费凭凭证扣除 |
| 税优健康险 | ≤ 2,400 元/年 | 凭税优识别码，200 元/月 |
| 公益慈善捐赠 | 按填报额扣除 | 需符合「不超过申报应纳税所得额 30%」等条件；超限时页面会给出提示，但仍按填报额参与测算 |

### 2.6 全年一次性奖金（年终奖）

**方案 A：单独计税**（政策延续至 2027-12-31）

```
年终奖应纳税额 = 年终奖收入 × 月度税率 − 月度速算扣除数
```

月度税率按「年终奖 ÷ 12」的商数确定（按月换算后的综合所得税率表）：

| 级数 | 月均金额（元） | 税率 | 速算扣除数（元） |
|---:|---|---:|---:|
| 1 | 不超过 3,000 | 3% | 0 |
| 2 | 超过 3,000 至 12,000 | 10% | 210 |
| 3 | 超过 12,000 至 25,000 | 20% | 1,410 |
| 4 | 超过 25,000 至 35,000 | 25% | 2,660 |
| 5 | 超过 35,000 至 55,000 | 30% | 4,410 |
| 6 | 超过 55,000 至 80,000 | 35% | 7,160 |
| 7 | 超过 80,000 | 45% | 15,160 |

**方案 B：并入综合所得**：把年终奖全额并入综合所得收入额，按 §2.2–§2.3 统一计算。

两方案比较口径：

- 方案 A 全年税额 = 综合所得（不含年终奖）税额 + 年终奖单独税额；
- 方案 B 全年税额 = 年终奖并入后的综合所得全年税额；
- 推荐税额较低者（两者相同时默认单独计税，避免汇算时额外选择），并展示差额。

**年终奖临界点**：36,000 / 144,000 / 300,000 / 420,000 / 660,000 / 960,000 元。奖金刚超过临界点时，月均商数跳档、税率跳升，可能出现「多发 1 元多缴数千元」。经典例子：

- 36,000 元 → 1,080 元；36,001 元 → 3,390.10 元（多发 1 元，多缴 2,310.10 元）；
- 144,000 元 → 14,190 元；144,001 元 → 27,390.20 元（多发 1 元，多缴 13,200.20 元）。

### 2.7 工资薪金累计预扣法

工资薪金按「累计预扣法」逐月预扣，预扣率使用年度税率表（§2.3）：

```
累计预扣预缴应纳税所得额
  = 累计收入 − 累计基本减除费用（5,000 元/月 × 月数）
    − 累计专项扣除 − 累计专项附加扣除 − 累计其他扣除

本月应预扣税额 = 累计应纳税额 − 累计已预扣税额
```

本模块按 12 个月生成预扣明细：

- 工资按月均摊（第 m 月累计收入 = 年工资 × m ÷ 12）；
- 大病医疗扣除不计入累计预扣（按政策只能汇算扣除）；
- 年末累计预扣税额即全年工资已预缴税额；
- 劳务报酬、稿酬、特许权使用费按「全年一次性支付」的预扣规则估算已预缴额（见 §6 误差说明）。

### 2.8 汇算应补 / 应退税

```
全年应纳税额（推荐方案） = 综合所得应纳税额 + 年终奖单独税额（若单独计税）
全年已预缴税额 = 工资累计预扣 + 其他所得预扣估算 + 年终奖单独预扣
应补（退）税额 = 全年应纳税额 − 全年已预缴税额
```

正数为应补税，负数为应退税。若单位已按单独计税预扣年终奖、而汇算选择并入综合所得，则年终奖预扣额也参与抵减，产生相应退税或补税。

### 2.9 综合税负率

```
综合税负率 = 全年应纳税额 ÷（综合所得收入额 + 全年一次性奖金收入）
```

页面以万分位整数存储（100 = 1.00%），展示保留一位小数；收入为 0 时显示 0.0%。

## 3. 整数运算与四舍五入

为了让 App 结果与税务口径一致，**所有金额以「分」为单位的 `Long` 存储与计算，全程不经过 `Double`**：

| 运算 | 规则 |
|---|---|
| 百分比折算（如 ×80%、×3%） | `round(金额分 × 百分数 ÷ 100)`，四舍五入到分 |
| 千分比折算（如失业 0.5% = 5‰） | `round(金额分 × 千分数 ÷ 1000)` |
| 税额 | `round(应纳税所得额分 × 税率 ÷ 100) − 速算扣除数分`，结果小于 0 按 0 |
| 分档判断 | 按「分」比较上限（如 36,000 元 = 3,600,000 分），`≤` 命中当前档 |
| 金额上限 | 单项输入上限 1 亿元（防止整数乘法溢出）；负数按 0 处理 |

四舍五入使用显式的「加半个单位再整除」：`(被乘数 + 除数/2) ÷ 除数`，并单独处理负数符号。税率表命中、四舍五入、金额上限三类规则集中在 `TaxRules.kt`，便于单测覆盖。

### 4.3 三险一金估算公式

月工资基数 × 个人比例：养老 8%、医疗 2%、失业 0.5%、住房公积金 5%–12%（用户可选），四舍五入到分，年度合计 = 月缴 × 12。

例：月薪 25,000 元、公积金 12% → 养老 2,000 元 + 医疗 500 元 + 失业 125 元 + 公积金 3,000 元 = 5,625 元/月，年度 67,500 元。

## 5. 页面结构与交互

「个税测算」页（`ui/screens/tax/TaxScreen.kt`）采用五步向导，任意步骤可回看修改，结果随输入实时更新：

1. **收入**：工资薪金（年度）、全年一次性奖金、劳务报酬、稿酬、特许权使用费；实时显示计入综合所得的收入额；可展开「收入额折算」政策说明。
2. **三险一金**：月工资基数 + 公积金比例（5%–12%），「按工资基数自动估算三险一金」一键填入四项月缴额（注明为估算、不含缴费基数上下限），也可手动修改。
3. **专项附加扣除**：7 项逐项编辑——子女数 / 婴幼儿数 + 分摊比例、继续教育学历月数 + 职业资格、房贷利息开关、住房租金三档（与房贷互斥）、赡养老人独生 / 非独生分摊、大病医疗自付累计；每项可展开政策说明，底部显示年度合计。
4. **其他扣除**：个人养老金（≤12,000）、税优健康险（≤2,400）可一键填上限，公益慈善捐赠按填报额扣除并提示 30% 限额条件。
5. **结果与模拟申报**：
   - 应补 / 退税总额、全年应纳税额、已预缴、应纳税所得额、综合税负率、适用税率、速算扣除数、各扣除项；
   - 年终奖「单独计税 vs 并入综合所得」两方案对比表（应纳税额 / 已预缴 / 应补退）与推荐、差额；
   - 12 个月累计预扣表（横向可滚动）；
   - 模拟申报 11 项表格（收入额 / 减除费用 / 专项扣除 / 专项附加扣除 / 其他扣除 / 应纳税所得额 / 适用税率 / 速算扣除数 / 应纳税额 / 已缴税额 / 应补退税额）；若推荐「单独计税」，表格只体现综合所得，年终奖单列说明、不占用表内已缴税额；若推荐「并入综合所得」，表格含年终奖收入额与单独预扣的抵减；
   - 「分享测算结果」（系统分享）、免责声明、「计算器自检」入口。

页面顶部固定展示政策依据与适用年度；所有可点击元素带触感反馈（`Haptics` / `Modifier.syClickable`），数字使用衬线字体、金额千分位、比率一位小数。

## 6. 误差说明与计算假设

本模块是「估算 / 规划工具」，以下情形与正式汇算可能存在差异：

1. **工资按月均摊**：12 个月预扣表按年工资平均发放估算；实际月度发放不均（含年终奖、补发工资、月度扣除项目变化）会改变各月预扣分布，但设计上不影响年末累计预扣总额。
2. **劳务报酬 / 稿酬 / 特许权使用费预扣估算**：现实中按「每次支付」预扣，本模块把全年收入视为一次支付，属于偏保守的估算；若实际分多次支付，已预缴额会与估算不同，汇算的应补 / 退税额需以实际预缴为准。
3. **三险一金为估算**：按用户填写的月缴额 × 12，或按工资基数 × 固定比例估算，未考虑社保缴费基数上下限、公积金基数上限、工作月数不足 12 个月等情况；请按实际缴纳额修改。
4. **专项附加扣除按月满 12 个月**：子女教育、婴幼儿照护、赡养老人、房贷利息、住房租金默认全年扣除；年中开始/结束、房贷提前结清、租赁合同不满一年等情形请按实际月数调整（当前页面仅继续教育支持月数自定义）。
5. **大病医疗**：仅支持按全年自付累计计算，且只在汇算时扣除；配偶、未成年子女的大病医疗扣除需按人分别归集。
6. **公益捐赠**：按填报额直接扣除并提示 30% 限额，未实现超限部分结转以后年度扣除的计算。
7. **未覆盖的税收事项**：减免税优惠、境外所得抵免、全年一次性奖金以外的特殊计税、补税豁免（年收入不超过 12 万元或补税不超过 400 元）、税收协定、专项附加扣除的重复申报校验等。
8. **年终奖方案对比只比较「全年应纳税额」**，不考虑单位预扣方式、申报操作成本、跨年发放等现实因素；年度汇算申报以个人所得税 App 为准。
9. **四舍五入到分**：税额计算结果保留到分并四舍五入；申报系统可能按元或分处理，尾差一般在 1 分以内。
