# 岁余 · 命名与品牌

## 一、主名：岁余

**出处**：《庄子·庚桑楚》——「今吾日计之而不足，岁计之而有余。」

原文：按天算总有不足，按年看反而有结余。这不是理财格言，而是一种看账的尺度，产品正是把这层意思装进家庭账本：

- **岁**：以年为单位的账期，对应年度汇总与年度报表。
- **余**：结余，也指从容——不必为每天细账焦虑，一年下来还有剩余。

三个好处：准确，它直指产品核心「年度结余」；克制，两个字，不卖萌、不承诺收益；有余地，「将满未满」正是家庭财务最健康的状态。

**Slogan**：日计不足，岁计有余。

备选 Slogan（用于商店副标题、分享页脚）：一年一本家庭账；把每一笔，算进一年里。

**书写规范**：中文一律写「岁余」，不加引号与后缀；英文名 Suiyu；包名 `com.suiyu.ledger`；不写成「岁餘」，也不与「年年有余」等吉祥话混用。

## 二、备选名对比

决策依据来自 `docs/市场与产品调研.md` 的命名冲突核查（2026-11-21 公开商店检索；不等同于商标与软著检索）。

| 候选 | 出处/含义 | 调研中的风险 | 结论 |
|---|---|---|---|
| **岁余** | 《庄子·庚桑楚》，年度结余 | 未发现同名记账 App；与「小满」「度支」「知盈」等已占用名无关 | **采用**（仍需补做商标检索） |
| 岁计 | 同源，指年度总账 | 与「岁余」同源，语义更偏「总账」，少一点温度 | 备选，适合更专业的报表版 |
| 拾穗 | 拾麦穗，寓意积少成多 | 已有「拾穗」笔记 App 与浏览器扩展（非记账），风险中高 | 不采用 |
| 见微 | 见微知著，从细节看趋势 | 已有「见微数据」App 及同名健康产品，风险中高 | 不采用 |
| 盈虚 | 《易经》盈虚消长 | 未见同名 App，风险低（商标待查）；「虚」字在记账语境里偏消极 | 不采用 |
| 仓廪 | 《管子·牧民》「仓廪实而知礼节」 | 稳重有纵深，但偏宏大，不够贴近日常记账 | 备选 |
| 三余 | 《三国志》「冬者岁之余，夜者日之余，阴雨者时之余」 | 双关「有余」；但字面易被误解为「三笔余额」 | 备选 |

另有三类名字因冲突风险高直接放弃：**小满**（已有「小满记账」「钱小满」）、**度支**（已有同名记账 App）、**知盈**（已有家庭资产管理 App）。商店检索只能近似判断冲突，立项前应补做第 9/35/42 类商标与工商核名检索。

## 三、图标寓意

应用图标由三样元素构成：

- **将满之月**：一枚米白色圆盘（`#F3E7C9`），用底色圆切出缺口，形成一弯上弦月。月将满而未满，寓意「有余」而不满溢。
- **三行账目**：月下方三条稻金短线（`#D9B97A`），长短相间，像账簿上的三行数字，也像收入、支出、结余三栏账。
- **黛青底色**：整体底色用主色黛青（`#24483E`），安静、耐看，和米纸色界面形成同一体系。

构成规则：只用黛青、稻金、米白三色；线条圆头、粗细一致；不添加文字、金币、元宝等常见理财符号。图标采用自适应图标（前景 + 纯色背景），在圆形、方形、圆角矩形裁切下都保持可读。

## 四、品牌语气

一句话：**像一个认真但不唠叨的家人，帮你把账算清楚。**

- **克制**：说事实、给数字，用「本月支出比上月少 12.4%」，不用「你终于省钱了！」。
- **专业**：术语准确，单位清楚；个税说「测算」「参考」「以税务机关为准」。
- **有温度**：可以有「这一年辛苦了」的收束，但不卖萌、不用网络热词。
- **不制造焦虑**：不吓唬「再不记账就晚了」，不比较同龄人，不做消费羞辱。
- **不承诺收益**：不提「帮你多退税」「理财赚钱」。

## 五、禁用文案与替换示例

| 禁用表述 | 问题 | 替换为 |
|---|---|---|
| 100% 全自动、一键自动记账 | 夸大识别能力，截图质量不可控 | 识别后逐条复核，确认入账 |
| 绝对准确、零误差 | 无法保证 | 以你填写的数字为准 |
| 帮你多退几千元、保证节税 | 承诺税务结果 | 测算结果仅供参考，以税务机关为准 |
| 卖萌与说教句式（「记一笔嘛～」「你怎么又乱花钱」） | 与专业克制语气冲突，或越过产品边界制造负罪感 | 用陈述句：「餐饮占本月支出 32%」 |
| 竞品名称与比较性文案 | 违反调研结论与合规边界 | 不提竞品，只讲自身选择 |

所有对外文案（应用商店描述、应用内提示、分享文本）都应通过这张表自检；涉及金额、税率、识别效果的内容一律加限定语。
