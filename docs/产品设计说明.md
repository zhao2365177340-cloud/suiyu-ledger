# 岁余 · 产品设计说明

> 版本 1.0 ｜ 2026-11-21 ｜ 适用范围：安卓版「岁余」
> 功能范围以 `docs/CONTRACT.md` 与源码为准；本文件说明产品为什么这样做。

## 一、产品定位

**一句话**：「岁余」是一款本地优先、无广告的安卓家庭记账 App——把账单截图整理成可核对的流水，把流水变成一张能分享的家庭月报，并顺带把个人所得税测算清楚。

名字取自《庄子·庚桑楚》「今吾日计之而不足，岁计而有余」。日计是每天的细碎收支，岁计是一年的结余。产品不做「每天催你记账」的工具，而做「一年下来能看明白」的家庭账本。Slogan：**日计不足，岁计有余**。

三条不可动摇的边界：

1. **数据在本机**。账本存于应用私有目录的 `ledger.json`，无账号、无云同步、无广告、无埋点；OCR 走端侧离线模型，不上传图片。分享与导出只由用户主动发起。
2. **不做会员墙**。导出 CSV、导出 JSON 备份、分享报表、个税测算全部免费，不存在「付费才能看数据」。
3. **专业但不冷**。中文书面语、衬线数字、细线分隔，像一张印在米纸上的报表；可以有温度，但不卖萌、不说教。

## 二、目标用户与典型场景

| 用户 | 特征 | 最在意的事 |
|---|---|---|
| 双职工家庭「管账人」 | 25–40 岁，共同承担房贷、育儿与日常开销，习惯微信/支付宝/银行卡付款 | 月底说清钱花在哪、成员各花多少、与上月相比如何 |
| 有非工资收入者 | 自由职业、副业、年终奖或劳务报酬 | 年收入与可抵扣项一次算清，汇算时心里有数 |
| 隐私敏感、反感广告者 | 被开屏广告、会员墙、数据上云劝退 | 装完就能用、数据随时可导出、不注册 |

**场景 A｜月初对账**：用户把微信、支付宝、银行的收支明细截了 8 张图，一次性选入「导入账单」。OCR 在本机逐张解析成草稿，金额、商户、日期、来源一目了然；只复核没把握的几条，改分类后全选入账，不必逐笔手打。

**场景 B｜月底的家庭月报**：打开「报表」选本月。页面像一张纸：总述说清收入、支出、结余与结余率，再依次是总览、结构、环比、成员分账、财务健康与洞察。点「分享报表」即可把纯文本月报发到家庭群，另一半不装 App 也看得懂。

**场景 C｜年初的个税测算**：填工资、年终奖、劳务报酬，按提示补三险一金与七项专项附加扣除，得到年度应纳税所得额、适用税率、应纳税额，以及年终奖两种计税方案对比。结果页附模拟申报表与分享入口，仅作参考，最终以税务机关口径为准。

**场景 D｜年度家庭财务体检**：把存款、理财、股票基金、房产、车辆与欠款录进「财务体检」，补充职业、单位性质、收入稳定性与保障情况；App 结合近 6 个月流水算出净资产、应急金月数、负债率、月供收入比与六维评分，给出 3–5 条能直接执行的建议，并把摘要嵌进月度报表，和另一半一起看「家里现在安不安全」。

## 三、信息架构与导航

```
底部 Tab（5 项，中央为记一笔 FAB）
├── 概览      本月收支总览、环比、近 6 月趋势、快捷入口、成员分布、最近流水
├── 流水      按日滚动的完整流水账：筛选、点击编辑、长按多选、批量删除、一键清空
├── 统计      结构 / 对比 / 日历 三个分段，支持支出收入切换与家庭/成员视角
├── 报表      月度财务报表（阅读物），一键分享与个税测算入口
├── 家庭      成员、分类、偏好设置、数据导出与备份、关于
└── 记一笔（中央 FAB，编辑态复用同一页面）
二级页：账单导入、财务体检、个税测算、成员/分类编辑、设置子页
```

**为什么是 5 个 Tab**：调研显示主流是 3–5 个 Tab。v1.0 只有 4 个 Tab，「完整账单列表」由概览最近流水与统计下钻承担；v1.1 根据用户反馈补上第 5 个「流水」Tab——因为「逐日看明细、随时改一笔、多选删除」是记账工具的刚需动词，藏在二级页会持续产生「找不到」的成本。5 个 Tab 仍在上限内，截图导入与个税测算保持二级页。

**导航原则**：底部 Tab 始终可见；中央 FAB 全局可达；二级页一律带返回，且不丢失账期与筛选状态；系统返回手势行为一致。

页面职责：概览只给结论；流水只做逐日明细与增删改；统计只做分析；报表负责讲述，顺序固定；家庭负责配置与数据出口，破坏性操作二次确认；导入负责把截图变成流水，以草稿复核为核心。

## 四、核心流程

### 4.1 截图导入 → 复核 → 入账

1. **选择**：一次最多 9 张截图（微信收支明细、支付宝账单、银行 App 明细等），也可直接粘贴短信文本。
2. **识别**：端侧中文 OCR 提取文字与坐标，解析器还原「一行一条明细」，识别金额、时间、对方、收付款方向，过滤汇总行。
3. **复核**：生成草稿卡，逐条可改类型、金额、分类、成员、日期、备注；显示来源角标与识别置信度；与已有流水同类型、同金额、3 天内且商户/备注相近时标为疑似重复。
4. **入账**：全选或逐条确认后批量写入，同时记住「商户 → 分类」的纠正结果，下次同商户自动归类；完成后给出波纹式触感与结果反馈。
5. **兜底**：识别不出的截图提供「手动补录」出口，不把用户留在死路上。

定位是**草稿生成，而非自动入账**。用户对识别率的容忍度低于对事后纠错成本，因此力气放在可编辑、可去重、可学习规则上，而不是宣传识别率。

### 4.2 手动记账（≤3 步）

1. 打开即键盘，输入金额（金额以「分」存储，避免浮点误差）。
2. 点分类（13 个支出分类 + 7 个收入分类，先粗后细）。
3. 点「保存」完成；默认支出、成员为「我」、日期为今天。

成员、日期、商户、备注为可选展开项，不展开不影响保存；编辑已有流水时回填全部字段。保存有 Confirm 触感；金额非法或未选分类时按钮禁用并说明原因。

### 4.3 流水明细与删除

1. **按日浏览**：流水 Tab 以「日期分组 + 当日收支小计」滚动展示，每笔显示分类、成员、商户、账户来源、时间与金额；支持账期、支出/收入、成员三重筛选。
2. **编辑**：点任一笔进入编辑页，改金额/分类/成员/日期/备注后保存即更新；编辑页右上角垃圾桶可删除单笔。
3. **多选删除**：长按任一笔进入多选模式——顶部显示「已选 N 笔」和已选合计，底部工具条提供「全选 / 删除」；再点按可追加或取消选择，系统返回键先退出多选。
4. **一键清空**：流水页右上角「清空」可删除全部流水（保留成员、分类与设置），二次确认并提示先导出备份。
5. **触感**：长按用 LongPress 触感、进入多选用 Select、删除成功用 Success，删除确认按钮用 Warning 语义色，避免误触。

### 4.4 月度报表生成与分享

1. 进入报表 Tab，用月份切换器选择账期。
2. 自动计算本月/上月/去年同月汇总、环比与同比、分类结构、成员分账、财务健康指标。
3. 自动生成总述与洞察：只陈述可被数字验证的事实，不做价值判断。
4. 点「分享报表」，通过系统分享面板发送纯文本月报，接收方无需安装 App。

当月无数据时显示空态与引导，而不是一张全是「—」的报表。

### 4.5 财务体检与风险评估（v1.2）

1. **录入资产**：现金/活期、定期存款、理财/货基、股票基金债券、保单现金价值、自住房、投资房产、车辆、借出/应收、其他资产；每项可增删改，按当前可变现价值填写。
2. **录入负债**：房贷、车贷、消费贷、信用卡、亲友借款等，填剩余欠款与每月还款；月供进入现金流与月供收入比。
3. **填写工作与家庭情况**：职业/行业、单位性质、工作年限、收入稳定性、配偶是否在职、赡养老人的数、子女数、医保/重疾/寿险与保额；也可手动填写月固定收入/支出，留空则按近 6 个月流水估算。
4. **算风险**：净资产与资产结构；应急金月数（流动类资产 ÷ 刚性月支出）；资产负债率与月供收入比；近 6 个月储蓄率；六维评分（流动性 25%、负债健康 25%、收入稳定 20%、储蓄能力 15%、保障覆盖 10%、配置均衡 5%）与综合评级；按薄弱项生成建议。
5. **看结果**：完整体检页 = 净资产总览 + 评分环、现金流基线、六维雷达、关键指标、资产配置环图、资产/负债清单、工作画像、建议与可分享的纯文本报告；报表页嵌入摘要，首页有「家庭净资产」卡。

体检是**解释型工具**，不是理财产品：每条建议都对应一个可被数字验证的缺口（如「应急金还差 ¥XX 到 6 个月」），并说明模型的经验属性与免责边界。

### 4.6 个税测算与模拟申报

1. **收入**：工资薪金、全年一次性奖金、劳务报酬、稿酬、特许权使用费。
2. **三险一金**：可按工资基数估算，也可逐项填写。
3. **专项附加扣除（7 项）**：子女教育、3 岁以下婴幼儿照护、继续教育、住房贷款利息、住房租金、赡养老人、大病医疗；每项可展开查看政策说明。
4. **其他扣除**：个人养老金、税优健康险等。
5. **结果**：年度应纳税所得额、适用税率、速算扣除数、应纳税额、已预缴估算、应补/退税额、综合税负率；年终奖两种计税方案对比与推荐；12 个月预扣明细。
6. **模拟申报**：表格式呈现收入额、减除费用、各项扣除、应纳税所得额、税额与补退税额，可分享。

所有相关页面明确标注：测算结果仅供参考，不构成税务建议，最终以税务机关口径为准。

体检页的图表延续自绘体系：评分环用深墨绿底 + 亮色进度弧，六维雷达用同一套 chart 色板与细网格线，资产配置复用环形图；所有金额默认等宽衬线数字，保证扫读时数位对齐。

## 五、设计语言

### 5.1 色彩

取色来自中国色意象，浅色模式主色板如下（深色为对应暗色变体，不逐一罗列）：

| 语义 | 色值 | 用途 |
|---|---|---|
| 米纸 | `#F7F3EC` | 全局背景，像纸不像屏幕 |
| 墨 | `#211F1B` | 正文与标题，避免纯黑的生硬 |
| 黛青 | `#24483E` | 主色：按钮、选中态、导航、图表首位 |
| 稻金 | `#B08A4A` | 小面积强调与章节记号 |
| 朱砂 | `#B4432E` | 支出金额、警示、删除 |
| 青玉 | `#2C6B55` | 收入金额（与朱砂成对） |

规则：界面不硬编码颜色，统一走语义色（支出/收入/稻金/细线/图表色板）；金额正负与色彩一一对应；图表分类色为低饱和 10 色，兼顾色弱可读性；深色模式底色 `#121614` 系，保持同一气质而非简单反色。

### 5.2 字体、数字与间距

- 标题与大数字用系统衬线体（Display/Headline/TitleLarge），带账簿与报表气质；正文、按钮用无衬线，兼顾小字号效率。
- 数字用衬线、千分位；百分比保留一位小数；环比/同比等比率分母为 0 时显示「—」，绝不出现 NaN。
- 金额一律以「分」为整数存储与计算，展示时再格式化；税务计算同样如此，避免 0.01 漂移。
- 版心 560dp，左右 gutter 20dp；间距为 4 的倍数：4 / 8 / 12 / 16 / 24 / 32dp；卡片圆角 20dp、1dp 描边；分隔线 0.7dp 细线，只在需要断句时出现，不靠分割线堆层级。
- 组件全部复用统一实现：卡片、章节标题、按钮、标签、金额、统计块、空态、流水行、月份切换、数字键盘；图表全部自绘，不引入第三方图表库。

### 5.3 图表原则

每个图表只回答一个问题：环形答占比，排行答谁最多，分组柱答对比，折线答趋势，日历热力答哪天花得多。图表数值统一以「分」传入，避免页面各自换算导致口径漂移。

## 六、触感反馈分层

触感不是装饰，而是对操作语义的补充。共 10 种，可在设置中一键关闭并三档调节；无马达或不支持振幅控制的机型静默降级，不会报错。

| 语义 | 典型场景 | 设计意图 |
|---|---|---|
| Tick | 数字键盘、列表轻点 | 最轻的确认，不打断连续输入 |
| Soft | 卡片、流水行、返回 | 「点到东西了」的基础反馈 |
| Select | Tab、Chip、月份切换 | 短促双段，表示选择已生效 |
| Confirm | 保存、提交 | 明确两段节奏，表示动作已提交 |
| Success | 记账完成、导入完成、测算完成 | 上行音阶式多段，表示完成 |
| Warning | 疑似重复、额度提示 | 明显双段重击，引起注意但不报错 |
| Error | 删除、失败 | 最重双段，明确「发生了不好的事」 |
| Toggle | 开关切换 | 极短轻点，与开关状态同步 |
| LongPress | 需要长按的动作 | 中等反馈，提示「按住了」 |
| Wave | 批量导入完成 | 由轻到重五段波纹，表示一批数据落地 |

强度三档对应约 0.5 / 0.78 / 1.0 倍振幅，默认标准档。所有可点元素都必须有反馈，用统一点击扩展实现，避免漏配。

## 七、适配策略

| 项目 | 策略 |
|---|---|
| 20:9（1080×2400） | 主目标：底部 Tab + 安全区 + 滚动内容，单手可触达 |
| 19.5:9（1080×2340） | 同上，不写死高度，按内容自然撑开 |
| 16:9（1080×1920） | 首屏密度略降，允许滚动；不依赖固定比例排版 |
| 平板/折叠/横屏 | 版心限宽 560dp 居中，两侧留白；图表按容器宽度自适应 |
| 深色模式 | 跟随系统/浅色/深色三选一，同一套语义色切换暗色变体 |
| edge-to-edge | 状态栏与导航栏透明，按系统 insets 避让；Tab 页预留底栏空间 |
| 键盘 | `adjustResize` + `imePadding()`，不遮挡输入与保存按钮 |
| 文本与点按 | 金额不换行、标签可控截断；主要可点元素不小于 44dp，列表整行可点 |

## 八、与调研结论的对应

调研见 `docs/市场与产品调研.md`。本产品**只提炼原则，不复制任何竞品界面、文案或视觉**，应用内与宣传材料中也不出现竞品名称。

### 8.1 学的五件事

| 调研结论 | 本产品落点 |
|---|---|
| 记一笔压到 2–3 步、打开即键盘 | 金额→分类→保存，成员/日期/备注折叠 |
| 无广告、免注册可试用 | 无开屏广告、无账号、无追踪 SDK；首启即有示例数据 |
| 本地优先、数据主权、导出免费 | 本地 `ledger.json`；CSV、JSON 备份、报表分享全部免费 |
| 截图导入做成批量「草稿箱」 | 最多 9 图批量解析、逐条复核、疑似重复标注、手动补录出口 |
| 分类智能推荐 + 纠正 + 规则记忆 | 内置分类关键词；纠正后记住「商户→分类」，下次自动归类 |

另吸收「触感分层且可关闭」「家庭视角切换」两条原则。

### 8.2 避开的五件事

| 调研中的问题 | 本产品的明确选择 |
|---|---|
| 开屏广告、摇一摇跳转 | 不做任何广告位与跳转诱导 |
| 导出/搜索/隐私锁会员 | 导出、备份、分享、测算全部免费；隐私开关免费 |
| 功能臃肿、塞社区与理财 | 首版 5 个 Tab（含流水明细），不做社区、不做理财推荐、不做预算 |
| 默认几十个分类、夸大全自动 | 13+7 个一级分类；OCR 定位为「草稿 + 复核」 |
| 跨端二次收费、活动套路 | 无多端账号；不做返现、抽奖类活动 |

### 8.3 差异化落点

调研指出的空白点落到三处：**截图导入工作台**（批量、复核、去重、规则学习）、**个人/家庭双层报表**（成员分账 + 合并月报 + 环比同比 + 可分享）、**家庭税务测算**（扣除引导 + 年终奖两方案 + 模拟申报）。「专业简洁 + 全链路触感」与「本地隐私」贯穿全产品，不单列功能。

## 九、数据口径与质量底线

- **单一口径**：各页面共用同一套统计函数，同一笔钱在哪里看到一致；只统计「纳入统计」的流水；按本地时区自然月划分。
- **可解释**：自动文案只写能被数字验证的结论，如「餐饮占家庭支出 32%」，不写「你太爱喝奶茶了」。
- **可用优先**：按钮不可无响应；做不到的动作降级为明确提示，不做假交互。
- **空态与失败态**：列表、图表、报表都有空态引导，识别失败有手动补录出口。
- **隐私**：金额可遮罩为 `¥ ••••`；应用不申请网络权限；分享与导出均由用户主动触发。
- **合规**：个税一律说「测算」「参考」；不承诺识别准确率与节税收益，不使用「100% 全自动」「绝对准确」等表述。
